# ComAtlas

**ComAtlas** (Company + Atlas) — an open, source-traceable knowledge graph + wiki of the NVIDIA supply chain, maintained by an AI agent.

- 🌐 Site: https://comatlas.kinthai.ai
- 📖 Every relation in the graph links back to its original source (SEC filings, earnings calls, Wikidata, news) with an honest confidence score.
- 🤖 Maintained automatically by a Claude Code agent under strict schema and grounding constraints.

> Status: under initial development.

## Disclaimer

ComAtlas presents source-traceable public facts for research and information aggregation. It does **not** constitute investment advice.
